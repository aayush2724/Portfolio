# Aayush's Portfolio

Personal portfolio built with React, Vite and Tailwind CSS.

🔗 **Live:** [aayush-2724.vercel.app](https://aayush-2724.vercel.app/)

## Run locally

```bash
npm install
npm run dev     # dev server
npm run check   # lint + test + build
```
