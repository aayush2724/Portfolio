Privacy Policy

Effective 1 October 2026 · applies to aayush-2724.vercel.app

The short version

This is a personal portfolio run by Aayush Kumar. It has no accounts, no sign-up, no contact form, no comments and nothing for sale. The site itself does not set cookies and does not ask you for any personal information. The only data processing happens at the hosting layer (Vercel) and through a handful of requests your browser makes to load live project data, all described below.

What this site does not do

  • It does not create user accounts or store profiles.
  • It does not have forms that submit data anywhere. The “Contact” section is a plain email link that opens your own mail app.
  • It does not set cookies, and it does not use advertising, tracking pixels, fingerprinting scripts or social-media embeds.
  • It does not sell, rent or share any information about visitors.
  • The in-page “PortfolioBot” is a scripted keyword matcher that runs entirely in your browser. Nothing you type into it is sent to a server, and it is cleared when you close the page.

Hosting and analytics (Vercel)

The site is served by Vercel. Like any web host, Vercel receives the technical details of every request it serves — your IP address, browser and device information, and the page requested — in order to deliver the page and keep the service secure. Vercel's handling of that data is described in the Vercel Privacy Policy.

The site also uses Vercel Web Analytics. According to Vercel's documentation this records page views, the referring page, the country and region derived from the request's IP address, and the browser, operating system and device category. It does not use cookies; visitors are counted with a short-lived hash that cannot be used to identify a person or to follow you across other websites. I only ever see aggregate numbers (for example how many people viewed the projects section this week), never a list of individual visitors. Vercel's description of this product is at vercel.com/docs/analytics/privacy-policy.

If you prefer not to be counted at all, browser extensions and settings that block analytics scripts work as expected here — the site functions identically without the analytics script.

Requests your browser makes to other services

Some parts of the page load live data directly from third parties. When your browser makes these requests, the service on the other end receives your IP address and browser details, as with any web request. None of them receive anything you typed or clicked on this site.

  • GitHub (raw.githubusercontent.com and api.github.com) — when you open a project description, the project's README is fetched from its public repository so the text shown is the one the repository actually contains. READMEs can embed images hosted elsewhere; those load from whatever domain the README references. See the GitHub Privacy Statement.
  • github-contributions-api.jogruber.de — an open-source service that returns the public GitHub contribution calendar shown in the “Coding Stats” section. It is operated independently by its author, not by GitHub or by me.

Fonts are self-hosted on this site, so no request goes to a font provider. The LeetCode and GitHub statistics on the page are refreshed on a schedule by a script that runs on my side, not by your browser.

The site links out to GitHub, LinkedIn, Instagram, LeetCode and the live demos of individual projects. Those sites have their own privacy policies, which apply once you leave this one.

Browser storage

The site uses your browser's sessionStorage for two purely functional things: a flag so the intro animation plays only once per tab, and a cache of README text so a project you reopen is not downloaded twice. Both live only in your browser, are never sent anywhere, and are deleted automatically when the tab is closed. No cookies and no persistent storage are used.

If you email me

Clicking the email address on this site opens your own mail client. If you write to me, I receive your email address and whatever you send, I use it only to reply to you, and it stays in my mailbox like any other correspondence. Tell me if you would like a conversation deleted and I will do so.

Your choices and your rights

Because this site holds no personal data about its visitors, there is nothing for me to correct, export or delete on request beyond any email you have sent. Depending on where you live, data-protection law may give you rights over information that organisations hold about you; if you believe I hold anything of yours, or you have any question about this policy, email me and I will respond.

This site is not directed at children, and it does not knowingly collect personal information from anyone.

Changes to this policy

If the site starts doing something new with data — a contact form, for instance — this page will be updated first and the effective date at the top will change.
